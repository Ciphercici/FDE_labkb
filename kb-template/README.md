# 实验室知识库

> 自己的实战工作库：环境、资产、工具、流程、知识、报告，全部沉淀在这里。
> 权限只有两档：**维护人员可写，使用人员只读**。Git 管存储和版本，全员 Obsidian 客户端。

## 快速开始

- 维护人员：克隆仓库 → Obsidian 打开本目录 → 直接增删改 → push
- 使用人员：克隆仓库（只读）→ Obsidian 打开本目录 → 看文档 + 个人笔记写 `99_Personal/<你的名字>/`
- Agent：按 `_CONTEXT.md` 的行为准则接入（只读 + 日志）

## 目录说明

| 目录              | 内容                          | 谁能写          |
| --------------- | --------------------------- | ------------ |
| `01_环境`         | 实验环境：拓扑、版本清单、搭建记录           | 维护人员         |
| `02_资产`         | 实验目标：靶机、服务、账号（**仅实验环境**）    | 维护人员         |
| `03_工具`         | 工具手册：安装、用法、命令速查             | 维护人员         |
| `04_流程`         | SOP：实验步骤、操作规范、验收标准          | 维护人员         |
| `05_知识`         | 漏洞知识、原理备忘、**文章收藏**、踩坑记录     | 维护人员         |
| `06_报告`         | 实验报告、复盘、结果归档                | 维护人员         |
| `07_模板`         | 报告模板、测试计划模板                 | 维护人员         |
| `08_Agent_Logs` | Agent 操作日志（审计）              | Agent 只写自己目录 |
| `99_Personal`   | 个人笔记区（**不进 git**，pull 永不触碰） | 个人随便写        |
| `99_Archive`    | 归档                          | 维护人员         |
| `_attachments`  | 文章/报告图片附件（按文章名分目录）          | 维护人员         |
| `_tools`        | 自动化工具（抓取器、脚本）               | 维护人员         |

## 协作约定（详见 `_CONTEXT.md`）

1. 共享区（01-08）只读——维护人员除外
2. 个人笔记写 `99_Personal/<人名>/`
3. 贡献走人肉 PR：复制 → 修改 → 发给维护者合入
4. 真实凭据不写明文（用变量引用）

## 自动收藏

把公众号文章链接发到 QQ 群 → 机器人自动抓取保存到 `05_知识/文章收藏/`（工具见 `_tools/` 目录）。
