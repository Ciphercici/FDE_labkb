# 实验室知识库 · 全局上下文（Agent 必读）

> 这是知识库的说明书。**任何 Agent 接入前必须读本文档**，按本文档的约定行事。

## 一、库是什么

- 实验环境 / 资产 / 工具 / 流程 / 知识 / 报告 的沉淀库，Git 仓库管理，全员 Obsidian 客户端
- 权限两档：维护人员可写（Git push），使用人员只读（Git pull）
- 个人笔记区 `99_Personal/` 不进 git（.gitignore），Agent 不得写入

## 二、给 Agent 的行为准则

1. **共享区（01-08）只读**：除 `08_Agent_Logs/<自己的目录>` 外，不得修改任何共享文件
2. **按需读取**：search/read 只取命中片段（top-k），**禁止全量读取整个库**（token 红线）
3. **回答必须引用来源**：文件名 + 段落，不编造
4. **越权拒答**：权限外内容直接拒绝，不猜测、不推断
5. **操作留痕**：每次读写操作在 `08_Agent_Logs/<agent名>/<日期>.md` 追加记录
6. **真实凭据**：密码/密钥/令牌一律不读取、不输出（库内若有则按变量引用处理）

## 三、给人类的协作约定

1. 共享区（01-08）只读——维护人员除外
2. 个人笔记写 `99_Personal/<人名>/`（pull 永不触碰，注意自己备份）
3. 想给共享库贡献内容：复制 → 修改 → 发给维护者合入（人肉 PR）
4. 真实凭据不写明文，写变量引用（如 `{{LAB_SSH_KEY}}`）；资产清单必须标注"仅实验环境"

## 四、文章收藏（自动化工作流）

- QQ 群发公众号文章链接 → 机器人自动抓取 → 存入 `05_知识/文章收藏/`
- 命名：`<YYYY-MM-DD>_<文章标题>.md`，图片存 `_attachments/<文章名>/`
- 详情见 `05_知识/文章收藏/README.md`
